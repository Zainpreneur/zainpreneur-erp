Active storage
The Turso auth token is kept server-side only in server.py (via TURSO_DB_URL and TURSO_AUTH_TOKEN env vars). It never reaches the browser.
To use Turso instead of the file fallback, run the server with:
export TURSO_DB_URL="https://<db>.<user>.turso.io" export TURSO_AUTH_TOKEN="your-token" python3 server.py
